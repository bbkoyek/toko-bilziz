endpoint admin (127.0.0.1:2000/toko/admin)

- POST
kirim data lewat form data

contoh key
	"name"
	"deskripsi" (opsional)
	"harga"
	"image" (opsional)

response
{
    "data": "nil",
    "message": "berhasil create data",
    "status": "success"
}

- GET
tanpa ada input atau data yang di kirimkan, format response berupa json
{
    "data": [
        {
            "Id": ,
            "name": "",
            "deskripsi": "",
            "harga": ,
            "image": []
        }
    ],
    "message": "berhasil ambil data",
    "status": "success"
}

- PUT
pengiriman data lewat form data
contoh key
	"Id"
	"name"
	"deskripsi"
	"harga"
	
	tidak usah di sertakan jika tidak ingin di jalankan
	"delete_image" (opsional jika ingin hapus gambar isi dengan nama gambar yang ingin di hapus)
	"image" (opsional jika ingin menambahkan gambar)

ketentuan
- wajib ada id
- bisa edit (name,deskripsi,harga,gambar(add,delete)) bisa semua dan juga bisa salah satu

- DELETE
mengirimkan data id ke BE lewat form data dengan key id

user / umum
